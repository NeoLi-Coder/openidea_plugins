# Neo API 工具 0.1.14

点右侧的黄色闪电 ⚡ 打开「API 工作台」。切到「接口树」，或按 Ctrl+Alt+/，可按路径、类、方法或模块查找接口。展开模块和控制器，点接口进入它的请求标签，点定位图标跳到源码。改了映射后点刷新重新读取。

从接口树打开的请求，可以直接用第二行工具栏的定位按钮跳到当前标签对应的方法，或在接口树中展开并高亮它。收藏和历史会记住接口来源；手填、cURL 导入和未记录来源的旧请求没有定位目标。

**从源码打开接口**：在 Java / Kotlin 编辑器中，点击映射方法声明行左侧的闪电，在工作台打开可编辑请求；同一方法有多个地址时先选地址。点击控制器类名旁的闪电可从该类的接口中选择。此操作不发送、不自动收藏；重复点击会回到已打开的请求标签。识别范围与下文的 Spring 和 JAX-RS 接口解析一致。

**从源码执行一次定时任务**：首次在「设置 → 插件 → Neo API 工具」允许 `java.agent`，然后用 OpenIDEA 的本地 Spring Boot 或 Application 运行配置启动服务（已经运行的重启一次）。应用就绪后，点无参同步 `@Scheduled` 方法旁的 ⚡ 即可提交一次。无需填写 VM options，不改变原有 cron。发送使用 `process:curl`，已授权的 curl 可继续使用。

工作台只列当前项目注册了该方法的本地运行实例；有多个时先选实例，实际执行结果看应用控制台。没有匹配实例时不执行，也不在服务启动后补跑。自动加载针对 IDE 直接启动的本机 JVM，不包括 Maven、Gradle 委托启动或远程进程。撤销 `java.agent` 后，新启动的服务不再加载组件；组件 JAR 变化时需重新批准。0.1.8 已手工配对的运行实例仍可用；切换自动模式时，只移除之前追加的 Neo `-javaagent` 参数，保留其他 VM 参数。

工作台默认使用「本地开发」（`http://localhost:8080`），地址可修改，但不能保存为空或删除此环境。已有项目保留已选环境和原有地址；以前未选环境的项目直接使用「本地开发」。公共请求头仍独立配置，首次预填 `Accept: application/json`，保存后才生效。

工作台弹窗紧贴触发按钮下方打开，「新环境名称」也紧贴环境管理里的 ＋。下方放不下且上方更宽裕时，弹窗改在按钮上方显示。

**复用字段名**：例如在项目 A 保存环境变量 `satoken`，项目 B 的环境变量名称框输入 `sa` 就能选中它。点 ▾ 浏览全部，方向键和 Enter 选择，也可继续输入新名称。候选旁的 × 只删除本机共享建议，不删除项目配置。已有项目打开后会补入之前保存过的名称。环境变量、请求头、查询参数、表单和 Cookie 各用自己的名称库；保存配置、收藏请求或记入发送历史时收录，变量值、凭证和正文不进库。

- **多请求标签**：工作台首次打开或关闭最后一个请求后，编辑区留空。点 ＋ 可新建请求，也可以直接打开接口、收藏、历史或导入 cURL。再次点击同一接口会选中它的标签。每个标签独立保留输入、响应和控制台。发送过的请求可从历史重新打开；未发送的草稿要留到下次使用，请点工具栏的收藏图标。
- **填写请求**：在「参数」填路径和查询。例如 `/orders/{{id}}` 的路径值填 `42`；留空则使用环境变量。查询串与地址栏双向同步。参数、请求头、URL 编码表单可以勾选启用、填写说明、复制行和批量编辑；值栏按 Enter 进入下一行。Cookies 页编辑请求的 Cookie 头，认证支持 Basic 和 Bearer。正文支持 none、form-data（文本或文件）、x-www-form-urlencoded、raw。
- **发送**：首次发送，在插件权限中将 `process:curl` 授予支持响应头元数据的 curl 7.83 或更高版本，例如 Windows 自带的 `C:\Windows\System32\curl.exe`。不授予该权限也可以浏览、编辑与交换请求。
- **cURL**：粘贴单条 bash 风格命令生成草稿，检查后再发送；复制导出生成 bash 格式，可能包含授权信息。支持 URL、方法、请求头、Cookie、Basic、正文、普通表单文件、重定向、压缩及超时。未实现的选项会报出选项名，不执行粘贴的 shell 命令。暂不解析 cmd.exe 的完整转义规则。
- **环境**：点击工具栏的环境图标，直接填服务地址或分别填 Host、Port、ContextPath；取消不保存。启用「高级环境」可给同一环境添加多个项目和服务，再在工具栏逐级选择；选「默认地址」仍使用环境原来的 baseUrl。在请求工具栏切换当前环境，用 `{{变量}}` 在 URL、头部和正文中引用。未填的路径／查询参数需在发送前填写。新请求和从接口打开的请求在地址栏显示当前环境的实际地址，切换环境或项目服务时同步更新，保留已填的接口路径、查询和正文。其他环境未填服务地址时沿用「本地开发」的地址，不继承它的其他变量。导入或手动改写为固定地址的请求不随环境切换。工具栏的设置图标打开项目公共请求头。
- **收藏 / 历史**：每次提交发送都会记录，包括普通请求、下载、发送失败和发送后的取消；重复发送分别留档，显示发送时间及结果。校验未通过、附件尚未准备好或取消下载路径选择时还没有提交发送，不产生发送记录。收藏是历史中标记的条目，可直接在历史里收藏，填写名称、文件夹和说明；收藏未发送的草稿也会加入历史并标注「未发送」。取消收藏保留历史，删除历史同时取消该条收藏。在收藏／历史窗口搜索并点击记录，会在新标签打开。已有收藏会并入历史，找不到对应发送记录的旧收藏显示为「旧收藏」。记录及环境保存在本机插件存储，原样填写的凭证也会留在请求记录中；使用环境变量可避免把凭证复制到每一条记录。
- **上传文件**：点「正文 → form-data」文件字段旁的「选择文件」，选好后点「发送」。集合或数组参数支持一次多选，按同一字段名上传。选取方式支持单文件 16 MiB 以内；更大的文件仍可粘贴完整路径，由 curl 直接读取。选取的附件只在当前标签可用，收藏和历史只记文件名，再次打开时需重选；手填路径照常保留。
- **下载文件**：点地址栏旁的「下载」，选择目录并确认文件名，或直接填写保存路径。确认后只发送一次请求，curl 将原始响应写入文件；取消不发送。导出接口如果在源码里给出了可识别的文件名，会预填为建议名称。例如道路导出保留 POST 的 JSON 筛选条件，建议名称为「道路导出.xlsx」。
- **响应**：拖动分隔条调整请求与响应区域，或折叠请求设置。普通发送可预览正文／响应头、格式化 JSON、复制和换行；「传输」中预填输出路径的用法仍可用。发送遵循宿主的参数、时间与输出大小上限，取消使用 OpenIDEA 任务控件。

## 接口发现

Spring Java/Kotlin 使用 OpenIDEA 0.1.50 的解析组件：控制器级和方法级映射、常量、查询参数和请求头、请求 DTO 的 JSON 骨架。JAX-RS 支持源码中的常见类/方法 `@Path`、HTTP 方法、`@QueryParam` 和 `@HeaderParam`。未接入 IDEA 的库索引，不扫描编译依赖 JAR；界面按本机 Restful Api Tool 251.2.45 的工具窗口移植。没有移植 IDEA 的原生编辑器、请求前脚本、跨请求 Cookie 仓库。只提供 cURL 导入导出。

## 构建与安装

仓库根目录运行 `./build.ps1 -Plugin api-tools`。共享 SDK 与 Cargo.lock 位于仓库根；此模块的 `src/` 为宿主桥接和 curl 传输，`web/` 为请求模型、接口发现与工作台，`vendor/spring/` 为固定版本解析器，`tools/bundle.mjs` 生成内嵌界面资源。没有运行时 Node 或网络依赖下载。

构建默认运行请求历史测试。单独验证可在本模块目录运行 `node --test tools/history.test.mjs`，覆盖发送记录、失败和取消、收藏子集及旧数据迁移；使用模拟宿主 RPC，不发送真实网络请求。

选择包文件安装 `release/neo.api-tools-0.1.14.oiplugin`，或从磁盘安装本模块目录 `plugins/api-tools`。与 Neo 编辑器工具分别授权、安装和升级。
